🧩 Simple Projects Using Arrays (Java)

This repository contains 12 simple Java programs built to practice the fundamentals of arrays.
Each project demonstrates how arrays can be used for data storage, computation, and manipulation in real-world examples.

🚀 Features

Covers both 1D and 2D arrays

Includes logic for sorting, counting, and searching

Beginner-friendly and fully commented

Works on any standard Java compiler

📘 Project List

Student Marks Analyzer – Find average, highest, and lowest marks

Temperature Tracker – Weekly temperature analysis

Duplicate Finder – Detect duplicate numbers in an array

Array Reversal – Reverse array elements in-place

Even and Odd Counter – Count even and odd values

Sum of Positive and Negative Numbers – Separate and sum values

Sorting Names Alphabetically – Sort strings using arrays

Inventory Management System – Simple CRUD operations using arrays

Bank Transaction Summary – Track deposits, withdrawals, and balance

Voting System – Count votes and find the winner

Employee Salary Calculator – Compare employee salaries to average

Quiz Score Analyzer – 2D array program for total and average scores
